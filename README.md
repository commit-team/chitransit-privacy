# ChiTransit Privacy Policy

This repository exists for one reason: Google Play requires a **publicly reachable URL** for
an app's privacy policy, and the ChiTransit source repository is private.

**Published at:** https://commit-team.github.io/chitransit-privacy/

`index.md` is the policy and is the canonical copy — edit it here, not anywhere else. GitHub
Pages rebuilds on push, usually within a minute.

The URL is referenced by the Play Console listing, so treat it as permanent. Renaming this
repository or turning Pages off breaks the store listing.
